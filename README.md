# FM100 Prediction
Telegram Mini App + Express + Supabase.

This is a points-only sports prediction game: no wagering, deposits, or cash-out.

## Render
Build: npm install
Start: npm start
Environment variables: BOT_TOKEN, SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, ADMIN_IDS

## Supabase
Run schema.sql in SQL Editor.

## Telegram
After deployment, use BotFather to configure the bot's Menu Button or Main Mini App with the Render HTTPS URL.
Do not put BOT_TOKEN in frontend code or GitHub.
